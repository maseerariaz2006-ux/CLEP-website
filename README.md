# CLEP Website

Website for the **Child Labor Eradication Program (CLEP)**, a university-based NGO started in 2013 by DVM seniors of the University of Agriculture Faisalabad. CLEP supports adopted children through a small daily contribution of Rs 5 per person.

## Pages

- Home
- About
- Focus Areas (Funds, Parent Awareness, Character and Career Building, Health)
- Teams (Accounts, Media, Indoor)
- Contact

## Built With

- Python
- Django
- HTML and CSS

## How to Run

1. Install the requirements:

   pip install -r requirements.txt

2. Set up the database:

   python manage.py migrate

3. Start the server:

   python manage.py runserver

4. Open http://127.0.0.1:8000 in your browser.

## Project Structure

- config/ : Django project settings and main URLs
- clepapp/ : the website app (views, URLs, templates, CSS)
